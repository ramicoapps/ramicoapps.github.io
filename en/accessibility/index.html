Website accessibility statement

Updated 10.11.2026

1. Accessibility of this website

We want the website ramicoapps.github.io to be accessible to people with disabilities, and we keep working to improve it. This statement covers the website itself. Each of our apps has its own accessibility statement, which you can find on the app's page.

This statement describes the adjustments the website actually has. It is not a claim of full conformance with the Israeli standard IS 5568.

The adjustments were checked in November 2026 in Chrome on a computer and in a phone-sized view: keyboard navigation, 200% zoom and color contrast. The website has not yet been tested with a screen reader. This statement will be updated after that test.

The website is built and maintained by RamiCoApps. The adjustments are part of the website itself, with no external accessibility plugin or overlay.

2. What has been adjusted

Each page declares its language and text direction, and is built with headings and regions (header, navigation, main content, footer).

The app screenshots have text alternatives, and decorative images are hidden from screen readers.

The whole website can be used with a keyboard, and the focused element has a clear outline.

Pages can be zoomed to 200% without losing content, and the website adapts to phone screens.

Text and link colors meet contrast level AA.

The animated background at the top of the home page stops when the device is set to reduce motion. Nothing on the website flashes.

3. Known limitations

The app screenshots are images. Their text alternatives describe each one briefly, and the information about each app is also written as text on the page.

The app store links lead to external websites, whose accessibility we do not control.

4. Contacting us about accessibility

Found an accessibility problem on the website, or need information in an accessible way? We would like to hear about it and fix it. Please tell us the page, the problem, and the browser or assistive technology you used.

The business is run by one person, so there is no separate accessibility coordinator. We handle accessibility requests directly at the address below, which is also our general contact address.

Email: ramicoapps@gmail.com
