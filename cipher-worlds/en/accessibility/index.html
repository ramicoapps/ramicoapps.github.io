Accessibility Statement

Updated 8.11.2026

Version 1.0 · Effective date: 8.11.2026

Rami Cohen, an exempt dealer (osek patur) in Israel, under the trade name RamiCoApps, wants Cipher Worlds: Morse (the "Game") to be playable by as many people as possible, including people with disabilities. This statement describes, honestly, what the Game offers today and where it still falls short.

This statement is published voluntarily.

Accessibility features in the Game

  • Screen readers (TalkBack / VoiceOver): buttons, icons and game elements have accessibility labels and roles, so a screen reader can describe them.
  • Dot and Dash buttons instead of the timed key: when a screen reader is on, the Game automatically uses on-screen Dot and Dash buttons instead of the timed Morse key (holding a key for a precise time is not possible with a screen reader). Rhythm-based questions are adapted accordingly.
  • Reduced motion: Settings → Animations lets you follow the device's "reduce motion" setting, or choose Reduced or Full. With reduced motion, effects such as confetti and spinning animations are turned off or simplified.
  • Signals without sound: when sound is turned off, Morse signals are shown visually on the screen, so you can play without hearing them.
  • Adjustable playback speed: you can choose a slower or faster Morse playback speed (Slow / Normal / Fast) for practice, challenges and the Code Map. Levels use their own set speed.
  • Tap timing: you can tune the Morse key to your own tapping rhythm, or go back to the standard timing.
  • Sound, music, effects and vibration can each be turned on or off separately, and the Morse tone volume can be adjusted.
  • Text size: the Game follows the device's font-size setting, up to a limit (about 130%) so the layout stays readable.
  • Colour contrast: text colours are checked against their backgrounds for contrast in development.
  • Languages: the interface is available in English and Hebrew (with right-to-left layout).

Known limitations

  • No formal accessibility audit has been carried out. We do not claim that the Game conforms to Israeli Standard IS 5568 or to WCAG.
  • Some questions rely on hearing Morse signals or on timing; the alternatives above may not cover every case equally well.
  • Text scaling is capped, so very large font settings are not fully applied.
  • Some parts of the Game are highly visual (for example Pip's World and decorative animations), and not every decorative element is described to screen readers.
  • The Game has not been systematically tested with every screen reader, switch-access or external-keyboard setup. It has not yet been tested on iPhone/iPad.
  • Ads are provided by Google, and their accessibility is not under our control.

Contact for accessibility

If you have difficulty using the Game, or have an idea that would make it more accessible, please write to us. Please describe the problem, the screen, and your device and assistive technology if you can.

  • E-mail: ramicoapps@gmail.com

RamiCoApps is a one-person business, so there is no separate accessibility coordinator; requests are handled by the developer. We will do our best to reply and to help.

Updates
